# 分析规范

## 先定口径

- 明确指标定义：分子/分母、去重键、时间粒度（日/周/月）、时区。
- 明确范围：全部数据还是抽样；是否包含测试账号、已删除记录、退款订单。
- 一次分析只改一个口径；需要对比时保持其他条件一致。

## 对比与基线

- 同比看去年同期，环比看上一个完整周期；避免用不完整周期直接对比。
- 给出基线与变化幅度，而不是只报绝对值。
- 分组对比时检查样本量；小样本结论标注置信度不足。

## 缺失值与异常

- 先统计 `NULL` 与空字符串比例，再决定：剔除、填补还是单独成组。
- 极端值先确认是否为真实业务事件（大客户、批量导入）再决定是否剔除。
- 金额、比率注意除零；`NULL` 参与的比较结果仍是 `NULL`，用 `IS NULL` 判断。

## 查询习惯

- 明细查询必须带 `LIMIT`；聚合优先于拉全量明细。
- 先聚合到目标粒度，再关联维表，避免关联后放大行数。
- 多表关联时确认关联键唯一性，必要时先去重或预聚合。

## 结论表达

- 结论 → 依据 → 局限，三段式；数字保留与业务匹配的精度。
- 任何假设都显式写出（例如"按支付时间统计，未剔除退款"）。
- 数据不足以支撑结论时直接说明，并给出下一步验证建议。
- 多维度分析配有多张图表时，采用「概要结论 → 分维度小节（每节洞察紧跟对应图表）→ 局限与建议」图文混排，避免先堆大段纯文字再在文末集中列图。
